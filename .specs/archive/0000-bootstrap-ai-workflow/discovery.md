# Descoberta

O repositorio contem frontend Next.js/React/TypeScript, backend ASP.NET Core `net10.0`,
PostgreSQL com EF Core, MinIO, Evolution API, Docker Compose e documentacao de Coolify.

A API segue um monolito modular com camadas Domain, Application, Infrastructure e Api.
O frontend usa App Router e organizacao por features. Foram observados testes com xUnit e
Vitest, migrations EF Core, contrato OpenAPI e arquivos `.env.example`.

Nao foram encontrados `.specs/`, `.agents/skills/` ou workflows de CI/CD antes desta mudanca.
Build, testes e lint nao foram executados durante a descoberta.
